# Installation Guide

This document explains how to install Spec-Kit-Plus safely and correctly.

## Requirements
- Python 3.9 or newer
- pip or uv installed
- Terminal access (Command Prompt, PowerShell, or Bash)

## Recommended Installation

Install Spec-Kit-Plus globally using pip:

~~~bash
pip install specifyplus
~~~

Verify installation:

~~~bash
sp check
~~~

## Alternative Installation Using uv Tool

~~~bash
uv tool install specifyplus
~~~

---

If you want to uninstall Spec-Kit-Plus later:

~~~bash
pip uninstall specifyplus
~~~

or

~~~bash
uv tool uninstall specifyplus
~~~
