# Troubleshooting Guide

Here are common issues you might encounter and how to fix them:

## 1. `sp` command not recognized

- Restart your terminal or computer.
- Ensure Spec-Kit-Plus is installed (`pip install specifyplus`).
- Make sure Python and pip are added to your system PATH.

## 2. Installation errors

- Check that your Python version is 3.9 or higher.
- Update pip with:  
  ~~~bash
  pip install --upgrade pip
  ~~~
- Try installing again.

## 3. AI provider issues

- Verify your AI API keys and configuration.
- Check your internet connection.
- Consult your AI provider’s docs for troubleshooting.

---

If problems persist, feel free to open an issue in this repository.
