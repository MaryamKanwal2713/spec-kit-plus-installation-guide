# Spec-Kit-Plus Workflow

Spec-Kit-Plus guides your project through these main steps:

## 1. Define Project Principles

Use the `/sp.constitution` command to create the project’s development standards:

- Code quality expectations  
- Testing guidelines  
- Performance targets  
- User experience consistency

## 2. Describe What You Want to Build

Use `/sp.specify` to clearly explain the feature in plain language.

Example:  
> Build a photo organizer app with albums sorted by date. Albums appear on the main page and can be reordered by dragging. Photos show in a grid layout.

## 3. Choose the Technical Approach

Use `/sp.plan` to decide your tech stack and architecture.

Example:  
> Use vanilla HTML, CSS, and JavaScript with Vite. Store data locally using SQLite. Images stay on the user’s device.

## 4. Generate Development Tasks

Use `/sp.tasks` to convert your plan into actionable tasks.

## 5. Implement the Feature

Use `/sp.implement` to execute the tasks and build your feature.
